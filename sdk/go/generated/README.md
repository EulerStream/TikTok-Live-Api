## Documentation For Authorization


Authentication schemes defined for the API:
### api_key_query

- **Type**: API key
- **API key parameter name**: apiKey
- **Location**: URL query string

Note, each API key must be added to a map of `map[string]APIKey` where the key is: api_key_query and passed in as the auth context for each request.

Example

```go
auth := context.WithValue(
		context.Background(),
		eulerapi.ContextAPIKeys,
		map[string]eulerapi.APIKey{
			"api_key_query": {Key: "API_KEY_STRING"},
		},
	)
r, err := client.Service.Operation(auth, args)
```

### api_key_header

- **Type**: API key
- **API key parameter name**: x-api-key
- **Location**: HTTP header

Note, each API key must be added to a map of `map[string]APIKey` where the key is: api_key_header and passed in as the auth context for each request.

Example

```go
auth := context.WithValue(
		context.Background(),
		eulerapi.ContextAPIKeys,
		map[string]eulerapi.APIKey{
			"api_key_header": {Key: "API_KEY_STRING"},
		},
	)
r, err := client.Service.Operation(auth, args)
```

### jwt_key_header

- **Type**: API key
- **API key parameter name**: x-jwt-key
- **Location**: HTTP header

Note, each API key must be added to a map of `map[string]APIKey` where the key is: jwt_key_header and passed in as the auth context for each request.

Example

```go
auth := context.WithValue(
		context.Background(),
		eulerapi.ContextAPIKeys,
		map[string]eulerapi.APIKey{
			"jwt_key_header": {Key: "API_KEY_STRING"},
		},
	)
r, err := client.Service.Operation(auth, args)
```

a number of utility functions to easily obtain pointers to values of basic types.
Each of these functions takes a value of the given basic type and returns a pointer to it:

* `PtrInt`
* `PtrInt32`
* `PtrInt64`
* `PtrFloat`
* `PtrFloat32`
